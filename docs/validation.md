# Проверка версии 0.1.0

Проверено в Linux-среде разработки:

- CMake Release-сборка переносимой библиотеки и `recovery_tests`; CTest: 1/1 тестовый набор, 44 проверки прошли.
- Кросс-сборка Windows x64 через GCC / MinGW-w64 14 с `-Wall -Wextra -Wpedantic -Werror`: приложение, ресурсы и интеграционные тесты собраны.
- Windows `windows_integration_tests.exe` под Wine 10: 25 проверок прошли. Проверены удаление временного ограничения, точный UTF-16 `.reg` с BOM и исходным DWORD, отказ при устаревшем наблюдении, неизвестном значении и неподходящем типе. Реальные политики Windows не изменялись.
- Приложение запущено под Wine с виртуальным экраном. Проверены отрисовка, запуск диагностики и переключение страниц. Снимок — `interface-wine.png`.
- По таблице импортов MinGW-сборка приложения использует DLL Windows, без отдельных DLL GCC / libstdc++.

Wine не подтверждает совместимость с реальной Windows и не содержит Microsoft Defender. Статус «Служба не установлена» на снимке относится только к этой среде. GitHub Actions добавлен, но его запуск в этой сессии не выполнялся.

## Перед распространением

На тестовой Windows 10/11 проверьте запуск `.exe`, масштабирование на используемых мониторах, копирование журнала и открытие системных средств. В одноразовой виртуальной машине с отдельной учётной записью проверьте подтверждение, восстановление каждой из четырёх политик и обратный импорт сохранённого `.reg`. Проверьте отказ при невозможности записать копию. Работа на заражённой системе и удаление вредоносных программ не проверялись.
