# Проверка версии 0.3.0

## Автоматические проверки

- Linux CMake Release с предупреждениями как ошибками: три набора CTest прошли. Политики — 44 проверки; прежние функции — 75; новые игры и команды восстановления — 7709 проверок, включая перебор 569 законченных партий крестиков-ноликов, проверку решаемости пятнашек/Lights Out и последовательности «Саймона».
- Кросс-сборка Windows x64 через GCC / MinGW-w64 14 с `-Wall -Wextra -Wpedantic -Werror` проходит.
- Windows-интеграционные проверки под Wine 10: 43 проверки реестра, резервных копий, временных файлов, настоящих уведомлений создания/удаления/переименования, сохранения конфигурации Sandbox и приоритета собственного процесса прошли.
- Новый `ui_tests` запускает отдельный процесс приложения с тестовыми настройками. Проверяет все семь страниц, шесть игр и четыре категории инструментов, пиксели кнопок при стирании фона/отрисовке/нажатии/наведении, 84 цикла переключений и размеров, сворачивание и восстановление. Проверяется отсутствие таймера на статической странице и расход CPU ниже 150 мс за 600 мс простоя. Локальный прогон под Wine прошёл; измерено 0 мс CPU в этом интервале.
- Утечки GDI проверяются после прогрева всех страниц: число ресурсов не должно вырасти более чем на 12 после стресс-прогона. Wine не поддерживает GetGuiResources, поэтому **под Wine эта проверка пропущена**, а не считается успешной. На настоящем Windows-раннере нулевой или растущий счётчик приводит к ошибке теста.
- В GitHub Actions Windows запускает все пять наборов тестов и `windows_readonly_smoke.ps1`. Smoke-тест запускает чистый Windows PowerShell и CMD `/d`, проверяет справку SFC/DISM, запрашивает `reagentc /info`, записывает наличие командлетов Defender. Также разбирает настоящие семь скриптов, сгенерированных C++, через PowerShell Parser, не выполняя их. Машинный отчёт `windows-readonly-smoke.json` включается в ZIP.

Исходники версии 0.3.0 (`e81a8fd`) прошли [GitHub Actions № 6](https://github.com/Bezsmertny/SU---Added-by-Crimesql/actions/runs/38833007119): оба задания Windows и Linux успешны, включая все пять Windows-наборов, проверку GDI на настоящем Windows и PowerShell smoke-тест. Публикация ZIP разрешена workflow только после успешных заданий Windows и Linux для тега выпуска.

## Что исправлено в отрисовке

Кнопки перехватывают WM_PAINT, WM_PRINTCLIENT и WM_ERASEBKGND. Весь элемент рисуется в переиспользуемом буфере и переносится одним BitBlt, в том числе при прямых запросах owner-draw от Windows. Родительское окно использует композицию дочерних окон. Раскладка пакетно меняет только отличающиеся позиции и видимость; массового hide/show больше нет. Буферы пересоздаются только при изменении размеров.

Декоративная анимация обновляет небольшую область щита. На статических страницах таймер отключается; ожидание окна операции проверяется раз в секунду. Фоновая декоративная анимация прекращается при деактивации/сворачивании.

## Границы проверки

Автоматические тесты не запускают вирусы, SFC `/scannow`, DISM RestoreHealth, проверки Defender с удалением угроз, автономную проверку Defender и перезагрузку в WinRE. Это реальные изменяющие/длительные операции, а не безопасные тестовые команды. Их успешное завершение на конкретном ПК **не подтверждено**. Синтаксическая проверка PowerShell не подтверждает успешность восстановления системы.

Wine не является Windows Sandbox и реализует BlockInput заглушкой. Запуск Sandbox, работа с заражённой системой, снятие реальной чужой блокировки ввода, вход в WinRE и автономное сканирование требуют отдельной проверки на тестовой Windows. Наличие WindowsSandbox.exe не гарантирует включённую виртуализацию. «PowerShell администратора» — обычная Windows, а не WinRE.

Прежние ограничения сохраняются: журнал лаборатории содержит события всей Sandbox без привязки к конкретному EXE, часть событий может быть потеряна с явным уведомлением, записи удаляются при закрытии Sandbox. Снимки интерфейса под Wine относятся к тестовой среде; файловые события на снимке наблюдателя — безвредный тест.

Перед использованием с подозрительными образцами проверьте лабораторию на безвредном EXE в одноразовой VM Windows Pro/Enterprise/Education, включая отсутствие сети/буфера обмена/записи в папку образца. Отдельно проверьте свои DPI/мониторы, автозапуск после входа, бинды и откат .reg.
