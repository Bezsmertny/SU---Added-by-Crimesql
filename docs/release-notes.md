CrimeSQL dev system recovery 0.3.0 для Windows 10/11 x64.

- Исправлена отрисовка кнопок при нажатиях и смене страниц: собственная буферизация, без стандартной белой заливки и массового hide/show.
- Повторное использование GDI-буферов, перерисовка только области движущегося элемента; на статической странице таймер отключается.
- Ещё четыре игры: крестики-нолики, пятнашки, «Саймон», Lights Out. Всего шесть.
- PowerShell и CMD администратора, сведения WinRE и параметры расширенного запуска.
- SFC для проверки/восстановления, DISM RestoreHealth, точки восстановления.
- Быстрая и автономная проверка Defender, аудит автозагрузки Run/RunOnce и локальные отчёты.
- Добавлены автоматические стресс-проверки UI и безопасные проверки штатных инструментов Windows.

Распакуйте весь ZIP, закройте старую версию и запустите CrimeSQLRecovery.exe. CrimeSQLObserver.exe оставьте рядом.

PowerShell открывается в текущей Windows, не в WinRE. В стандартной WinRE обычно есть CMD, а PowerShell не установлен. Автономная проверка Defender требует подтверждения и перезагружает ПК: сохраните работу и подготовьте ключ BitLocker, если он используется. SFC/DISM исправляют повреждения Windows; они не заменяют антивирус.

Ограничения лаборатории Sandbox и восстановления чужих блокировок ввода описаны в README. Исправления системы, автономная проверка и перезагрузка не выполнялись в автоматических тестах.
