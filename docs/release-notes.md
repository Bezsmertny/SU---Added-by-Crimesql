CrimeSQL dev system recovery 0.2.0 для Windows 10/11 x64.

- Новое название, оформление, анимации и мини-игры на поиск пар и реакцию.
- Настраиваемые глобальные бинды для мыши, клавиатуры и диспетчера задач.
- Восстановление захвата курсора и фильтрации клавиш с явными ограничениями Windows.
- Добровольный автозапуск текущего пользователя, обычный/высокий приоритет приложения.
- Полная проверка через установленный Microsoft Defender.
- Лаборатория EXE через Windows Sandbox: файловые события создания, изменения, удаления и переименования внутри среды. Сеть и перенаправления отключены, папка образца только для чтения.

Скачайте CrimeSQL-dev-system-recovery-Windows-x64.zip, распакуйте всю папку и запустите CrimeSQLRecovery.exe. Оставьте CrimeSQLObserver.exe рядом.

Лаборатория требует Windows Pro/Enterprise/Education, виртуализацию и включённый компонент Windows Sandbox. Файловый журнал находится внутри Sandbox, содержит фоновую активность и не устанавливает авторство EXE; при закрытии среды удаляется. Приложение не запускает образцы на основном ПК.

Windows не позволяет снять чужую блокировку BlockInput обычным приложением; при полной блокировке ввода используйте Ctrl+Alt+Del. Утилита не заменяет антивирус и не гарантирует устранение заражения. Подробности и порядок использования находятся в README.
