CrimeSQL dev system recovery 0.3.1 для Windows 10/11 x64.

- Новая вкладка Инструменты → Шрифты → Вернуть системные шрифты.
- Восстановление регистраций Segoe UI, сброс его системных/пользовательских подмен и восстановление шрифтов меню, заголовков, сообщений, статуса и значков.
- Segoe UI Variable обрабатывается при наличии его файла в Windows 11.
- Перед записью сохраняется уникальная копия `.reg` в Backups. Ошибки доступа, копирования и отсутствие основных файлов не замалчиваются; при частичном сбое выполняется попытка отката.
- Проверки на временных ключах реестра включают настоящий импорт копии через reg.exe, сохранение посторонних настроек и откат при отказе записи. UI-тест проверяет подтверждение и отказ без запуска восстановления.

Распакуйте весь ZIP, закройте старую версию и запустите CrimeSQLRecovery.exe. CrimeSQLObserver.exe оставьте рядом.

Для применения восстановленных настроек шрифтов сохраните работу, выйдите из учётной записи Windows и войдите снова. Автоматического выхода или перезагрузки нет. Нестандартные размеры шрифта этих элементов заменяются Segoe UI 9 pt с учётом системного DPI. Целостность файлов шрифтов не проверяется и файлы не скачиваются: если они повреждены, используйте SFC/DISM во вкладке «Система».

Точный путь копии показан в результате. При UAC под другой учётной записью копия хранится в Backups администратора, а настройки исходного пользователя адресуются по SID. Подробности отката и ограничения — в README. Автоматические тесты не меняют настоящие настройки системных шрифтов и не проверяют их применение после выхода из Windows.
